# Vue 2 移动端商城

## 项目简介

本项目是一个基于 Vue 2 开发的移动端电商商城前端，采用 Vue Router 实现页面路由管理，Vuex 管理用户与购物车状态，Vant 构建移动端交互界面，并通过 Axios 与后端 API 进行数据交互。

项目围绕电商购物流程展开，实现了商品展示、分类浏览、商品搜索、商品详情、购物车管理、订单结算及用户中心等功能，覆盖从商品浏览到提交订单的主要前端业务场景。

**本仓库仅展示前端开发部分，后端服务由独立接口提供。**

## 技术栈

- **Vue 2**：采用 Options API 和单文件组件开发页面。
- **Vue Router**：实现页面导航、路由懒加载及登录访问控制。
- **Vuex**：集中管理用户登录状态与购物车数据。
- **Vant**：构建移动端界面，包括轮播图、导航栏、标签栏、商品操作等组件。
- **Axios**：封装网络请求、请求与响应拦截器。
- **Less**：组织与维护页面样式。
- **LocalStorage**：持久化用户信息和商品搜索历史。

## 主要功能

**商品浏览与搜索**
- 商城首页商品展示和轮播图。
- 商品分类浏览、关键词搜索与历史记录。
- 商品列表展示与分页加载。
- 商品详情、商品评价及规格选择。

**购物车管理**
- 商品加入购物车。
- 商品数量增减及数量校验。
- 购物车商品勾选、全选与删除。
- 购物车数据与订单结算联动。

**用户与订单**
- 手机验证码登录。
- Token 状态管理及登录权限校验。
- 收货地址展示、商品金额计算与订单确认。
- 提交订单及个人订单列表展示。

**前端开发实现**
- 使用 Vuex 对购物车与用户信息进行集中管理。
- 封装 Axios 请求模块，统一处理 Token 携带、加载提示与接口错误。
- 封装商品卡片、数量选择器、订单列表等复用组件。
- 使用路由守卫控制结算页和订单页的登录访问。
- 通过 Vant 实现适配移动端的交互体验。

## 项目说明

本项目主要用于实践 Vue 2 组件化开发、Vuex 状态管理、移动端页面构建及电商业务流程实现。

项目通过已有后端 API 获取和提交业务数据，本仓库不包含后端服务代码。
